An interactive bioinformatics platform for exploring cancer-associated genomic variants across clinical, molecular, computational, and structural evidence layers.

---

## 1. Overview & Scientific Objective

The **Cancer Genomic Variant Explorer (CGVE)** is an open-source, academically rigorous web application designed to integrate and visualize multi-dimensional biological evidence for genomic sequence alterations in cancer driver genes (such as *TP53*, *BRCA1*, *BRCA2*, *KRAS*, *BRAF*, and *EGFR*).

### Scientific Philosophy
- **No Artificial Combined Scores**: CGVE strictly avoids collapsing independent biological dimensions into artificial pathogenicity indices, weighted averages, or risk percentages.
- **Attribution & Transparency**: ClinVar interpretations remain attributed to ClinVar submitters; computational predictions remain attributed to Ensembl VEP/dbNSFP; structural observations remain attributed to RCSB PDB and AlphaFold DB.
- **Preservation of Disagreements**: Conflicting ClinVar interpretations and discordant computational predictions are preserved and explicitly reported rather than masked.
- **Traceability**: Every interpretation statement generated by the platform is directly traceable to retrieved public source records.

## 3. Primary Biological Data Sources

| Source | Scope & Purpose | Link |
| :--- | :--- | :--- |
| **NCBI dbSNP / Variation** | RefSNP variant identity, genomic coordinates (GRCh38), RefSeq transcripts (`NM_`), and proteins (`NP_`). | [NCBI dbSNP](https://www.ncbi.nlm.nih.gov/snp/) |
| **NCBI ClinVar** | Live clinical interpretations (*Pathogenic*, *Benign*, *VUS*), submission counts, review stars, and conflicting assertions. | [ClinVar](https://www.ncbi.nlm.nih.gov/clinvar/) |
| **UniProtKB** | Canonical protein sequence entries, primary amino acid lengths, domain boundaries, and functional annotations. | [UniProt](https://www.uniprot.org/) |
| **RCSB PDB** | Experimentally determined atomic 3D structures (X-ray, Cryo-EM) covering the affected amino acid residue. | [RCSB PDB](https://www.rcsb.org/) |
| **AlphaFold DB** | Computationally predicted 3D protein structures with per-residue pLDDT structural confidence metrics. | [AlphaFold DB](https://alphafold.ebi.ac.uk/) |
| **Ensembl VEP / dbNSFP** | In-silico computational variant predictions (AlphaMissense, CADD, SIFT, PolyPhen-2) for target alleles. | [Ensembl VEP](https://www.ensembl.org/info/docs/tools/vep/index.html) |

## 4. Platform Features & Analytics

- **Gene Explorer**: Interactive query interface for cancer genes, displaying RefSeq transcripts, UniProt domain architectures, and ClinVar variant distributions.
- **Variant Explorer**: Detailed RefSNP resolution page with multi-allelic selector, ClinVar submission records, UniProt domain context, VEP functional predictors, and Stage 10 reconciliation status.
- **Variant Comparison**: Side-by-side analytical comparison interface comparing independently retrieved evidence profiles for two variant identifiers.
- **Analytics & Landscape**: Recharts dashboard displaying ClinVar significance distributions, molecular consequence breakdown, variant class proportions, and protein-position mutation density landscapes with domain sub-layers.
- **Interactive 3D Structural Viewer**: WebGL molecular viewer (`3dmol`) displaying experimental PDB or AlphaFold predicted structures, highlighting the target residue position, toggleable 5Å environment sphere, and per-residue pLDDT confidence.
- **Evidence & Scientific Interpretation**: Multi-layered factual synthesis summarizing molecular, clinical, computational, protein, and structural context without inventing pathogenicity scores.

## 5. Technology Stack & Architecture

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons
- **3D Molecular Visualization**: 3Dmol.js (WebGL rendering)
- **Data Visualization**: Recharts, Lucide React
- **API Serverless Layer**: Node.js ES Module Serverless Functions (`/api/gene.js`, `/api/variant.js`, `/api/services/*`)
- **Zero Paid Dependencies**: Designed for free static & serverless deployment (Vercel, Netlify) querying external biological REST APIs directly.

React Frontend (Vite)  ──►  Serverless API Functions (/api/*)  ──►  NCBI / ClinVar / UniProt / RCSB PDB / EBI APIs

## 6. Honest Scientific Limitations

1. **API Availability**: External REST APIs (NCBI, ClinVar, UniProt, RCSB PDB, Ensembl VEP) may occasionally undergo maintenance or rate limiting.
2. **Transcript Representations**: Alternative mRNA transcripts (`NM_` RefSeq IDs) can alter coding (`c.`) and protein (`p.`) HGVS residue numbering.
3. **AlphaFold pLDDT Metric**: pLDDT measures local structural prediction confidence (0–100); high pLDDT does not demonstrate clinical pathogenicity, nor does low pLDDT demonstrate benignity.
4. **Mutant Modeling Disclaimer**: CGVE highlights variant residue positions on reference PDB/AlphaFold structures; it does not perform in-silico mutant energy minimization or molecular dynamics simulations.
5. **Non-Diagnostic Notice**: CGVE is an educational and research software platform, not a medical diagnostic device. Clinical interpretations should be evaluated by qualified medical professionals.

## 7. Local Development & Deployment

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm (v9.0.0 or higher)

### Installation & Execution
```bash
# Clone the repository
git clone https://github.com/user/cancer-genomic-variant-explorer.git
cd cancer-genomic-variant-explorer

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```

### Serverless Hosting Configuration
- **Vercel**: Pre-configured via `vercel.json` rewrites for SPA routing and `/api` serverless functions.
- **Netlify**: Pre-configured via `netlify.toml` with redirect rules for client-side routing.
